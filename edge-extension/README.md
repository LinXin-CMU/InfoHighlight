# InfoLens Edge v0.8.13

默认“融合 → 重点句内分层”：普通句子保留纯信息密度的弱化效果，仅给重要度至少 75 分且排名前半的句子补可读下限，并按信息密度扩大醒目词数量。目标为纯信息密度的两倍；候选不足或并列时保留明暗层次，不强行提亮普通句。先显示 Base，再逐句补上 Mica 分数；“快速 → 仅信息密度”仍可用。本次代码升级需在扩展管理页重新加载一次，并刷新已打开的文章。之后调整外观直接重绘，无需重启。

打开托盘即预加载 Base、Mica 与专用翻译模型，任务切换与取消均保留权重。预加载状态可在工作台查看。

运行本机 InfoLens 服务并安装原有 Native Messaging 桥接；浏览器端ZIP只包含扩展文件，不含后台、模型或桥接程序。当前网页由 activeTab 显式授权，正文经本机桥接分析，不外发云端。内置PDF、跨域iframe和扫描件不在此扩展范围。
