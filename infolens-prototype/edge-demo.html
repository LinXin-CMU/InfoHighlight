Try Info Highlight. It uses large language models to analyze text information density and visualizes where the important parts are. The color intensity of each token indicates how much information it carries. Try it yourself!

InfoLens 使用本机的 Qwen2.5-1.5B Base，读取实际出现的下一个 token 概率，再计算 −log₂ p。分数通过 16 档颜色映射显示。字号、正文内容与段落结构由原网页保留。

重要约束：高惊讶度并不代表事实正确，也不一定意味着阅读价值。语义重要度需要单独验证；当前可切换 Base 概率、语义重点或融合；语义是有限上下文中的句子重要度。
