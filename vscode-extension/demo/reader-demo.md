# InfoLens Local Reader

Try Info Highlight. It uses large language models to analyze text information density and visualizes where the important parts are.

The color intensity of each token indicates how much information it carries. Try it yourself!

## 阅读约束

结果只在本机计算。原文修改之后，旧高亮必须立即失效。

暂停高亮只影响当前文档；卸载模型会释放显存，已显示的结果与内存缓存保留。

语义分数缺失时，融合退回信息密度；颜色强弱不表示事实正确率。
