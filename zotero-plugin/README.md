# InfoLens Zotero 0.8.17 Alpha

目标环境：Windows、Zotero 9.0.6。模型由 InfoLens Host 管理，显示偏好从工作台同步。需要配套的增量本机服务。

## 使用

1. 启动 InfoLens 本地服务，安装 InfoLens-Zotero-v0.8.17.xpi。翻译推荐配置专用 HY-MT1.5-1.8B NF4。
2. 打开带文字层的 PDF，自动优先分析当前页，再依阅读位置逐页补齐全文。Base 窗口完成后先显示已完成句子，再逐句更新语义。**暂停高亮／继续高亮**控制全文队列。
3. 点击 **翻译本页**。先按 PDF 字形宽度校准文字层，再按行距、字号、缩进和列边界合并成段落；公式区域与上下标保留 PDF 原有字形，旁边的正文独立排版；每次提交一段，优先处理阅读窗口中的段落。
4. 一段译文先显示，再由本地模型对译文本身评分，逐词补上高亮；高亮开启时，当前段评分完成后再翻译下一段，避免多条任务同时争用 GPU。滚动后，下一个未处理段落重新排序。已完成译文与评分保留。
5. **显示原文／显示译文**可以在任务中切换；暂停高亮、取消翻译均保留已完成部分。翻译结束或取消后，原先开启的全文高亮自动继续；手动暂停保持暂停。**清除**停止自动任务并清除全文临时结果。
6. 工作台 → 各应用显示 → Zotero 设置外观。修改后自动保存，约 0.5 秒同步并重绘已完成的原文高亮和译文，不重启、不重新推理。默认独立样式；勾选“跟随统一样式”后才跟随统一卡片。保存失败保留草稿，点击“立即应用”重试。

样式检查仅读取配置，未改变时不扫描阅读器、不重绘 PDF、不提交模型任务；同一时间只允许一个请求。阅读器补偿检查为 2.5 秒一次，切换标签与翻页由事件即时处理。没有打开 PDF 时不请求配置；关闭插件清理两个定时器和在途响应。

## 范围与限制

- 高亮按页缓存在当前阅读会话内，翻页不会清除。离屏页从 PDF.js 读取文本，避免强制滚动或渲染全文；缩放和文字层重建后重新定位。关闭阅读器释放缓存；重启后需重新分析。
- 切换标签立即更新当前页与文档进度，停止旧标签的未完成任务并保留已显示结果，优先分析新标签。返回后继续；手动暂停的标签保持暂停。等待 PDF 加载完成后才提交分析，不使用未知总页数。工具栏按阅读器／tab ID 绑定，同一附件多窗口互不混淆。
- 翻译仍以当前页为范围。翻到其他页会暂停该页后续翻译，但已完成译文保留。回到该页点击翻译可续传；可见段落始终优先。
- 原文与译文各自保存评分。译文视图只绘制译文本身的分值，未翻译区域保留原文墨色；切回原文时清除译文层并用原文范围重建高亮。译文尚未评分的部分正常显示。暂停高亮时只翻译，继续高亮后优先补齐当前页的译文评分。
- 只绘制当前阅读器的可见页，离屏页仅保存结果。文字位置、Range、段落几何、译文排版与底色采样均缓存；滚动不重新测量字形，无变化的重绘直接复用。每次绘制至多一次整页画布读回，避免逐字 GPU 同步；超过 1600 万像素时保留无法安全采样区域的原文。
- 增量校验 revision、contentHash、sequence 和完整源文本。复用图层，仅替换变化范围。语义缺失保持 null，完成后明确标示降级。
- 支持背景、下划线、真实文字色与弱化。文字色通过 screen 合成给原 PDF 字形着色，白色纸张保持白色；弱化把低分字形淡化到原底色，重点保留清晰。弱化强度 100% 时最低分保留 8% 字色，150% 时保留 3%；中低分按非线性曲线进一步淡化，最高档始终清晰，强度 0 恢复原文，未知分数保持原文。保持原字体、选区及复制。底色按 text run 抽样并缓存；不确定或彩色区域保留原文，不回退为下划线。原位译文按词应用相同显示曲线；背景、下划线、文字色与弱化均实时生效。
- 原位翻译是临时视觉替换，不修改 PDF、不写正式批注；复制、查找和选区仍使用原文。
- 译文在原文行框内流动。字号最低约为区域高度的 55%；放不下、非均匀浅色背景、定位失败的区域保留原文。
- 公式、脚注、复杂表格可能被拆成独立小段。段落提取与翻译质量仍是 Alpha，尚无完整质量基准。
- 扫描页、竖排和旋转页暂不支持原位翻译；恢复 0° 后可再次显示有效译文。
- 整页上限为 30,000 UTF-16 字符。取消整页 128 text run 限制；逐段提交，超过模型上下文预算的段落保留原文，不截断。
- 每段翻译等待上限 3 分钟；每页高亮任务上限 10 分钟。冷启动、排队、处理中和失败均显示反馈。文本不匹配、服务故障时暂停并保留结果，点击继续可重试。
- 保留 Windows 工具栏 no-drag 真实鼠标点击修复，按钮保持简短，进度显示在右下角。

## 隐私与更新

仅请求回环地址 127.0.0.1 的本机服务；凭据只在插件内存中，HTTP 不跟随重定向，日志不打印正文。原文、译文、任务与缓存只在本机内存处理；外观由 Host 保存。没有云端回退。

默认端口 43187，可通过整数偏好 extensions.infolens.port 修改并与 Host 保持一致。

HTTPS update_url 使用回环占位，关闭本插件后台更新。没有 TLS 自动更新服务；请手动安装 XPI。不会更改 Zotero 签名或更新安全策略。

## 实现入口

- core.js：文字快照、UTF-16 回源、段落几何、可见区域排序、局部高亮与译文绘制。
- infolens.js：工具栏、增量任务、段落队列、取消、工作台同步与原文切换。
- bootstrap.js：生命周期与本插件更新设置。
- 配套 infolens-prototype：鉴权队列、单份累积 partial 快照与本地 GPU worker。只缓存完成且有效的结果；取消后的增量不会进入缓存。

正文访问依赖已核对的 Zotero 9.0.6 Reader 内部对象。升级后需要重新验收。上游授权见 UPSTREAM-LICENSE.txt 与 UPSTREAM-NOTICE.txt。

## v0.8.10 平滑显示曲线

原文与原位译文采用两端平缓、中段增强、80% 起饱和的 S 形贝塞尔映射。最低文字可见度在强度 100% / 150% 时仍为 8% / 3%，零强度恢复原文，未评估文字保持原样。

## 0.8.17 公式保护与坐标修复

数学字体、符号编码和相邻上下标不送入翻译，也不盖白或弱化。行内公式保持原位，其两侧正文分开翻译；过窄的片段或排版放不下时保留原文。独立公式和编号保持原 PDF。嵌入字体不能用于文字层时，以 PDF advance width 校准整段宽度及 Range 的横向位置。此策略不从乱码反推 LaTeX，不改 PDF 文件、注释或检索文字。
